7/29 New Hyper-V VM + Docker Containers

docker hyper-v linux infrastructure

今天从零起了一台新的 Hyper-V Ubuntu Server VM，并把 MFS 项目的 6 个 Docker 容器全部跑起来。

新建 VM

本来想让 Qwen Code 直接通过管理员 PowerShell 建 VM，但 Qwen 对 Windows Terminal 的适配很差——终端疯狂闪烁、跳动，根本没法用。于是放弃 CLI，直接在 Hyper-V 管理器里手动新建，剩下的配置全部在 VM 里面搞定。

最终 VM 配置：

  • OS: Ubuntu 25.04 Server（Gen2 VM）
  • 用户: jimmyuser1
  • 网络: Default Switch，DHCP 拿到 172.24.97.180
  • 磁盘: 20G VHD，LVM 默认只分配了 10G

Hyper-V 建 Gen2 VM 记得关 Secure Boot，不然 Linux ISO 起不来。
