7/30 Database Backup System & Production Deployment

docker database devops fullstack

数据库自动备份系统

给 MFS 项目加了一套完整的数据库备份/恢复方案：

  • scripts/db-backup.sh — 通过 SSH 远程备份 ubsrv 上的 MySQL（dev + test 两套）
  • 支持 backup / restore / list / cron 四个子命令
  • 备份文件 gzip 压缩，存放在 db/backups/
  • 自动清理超过 7 天的旧备份
  • crontab 凌晨 3:00 自动执行，无需人工干预
  • 恢复操作有交互确认，防止误覆盖

实测两套环境各 92K，备份秒级完成。

生产环境部署到 jimmyuser2

VM 角色重新划分：

VM 角色
ubuntuserver (jimmy) 写博客 + Qwen Code
ubsrv (jimmyuser1) 开发 + 测试
jimmyuser2 生产环境

prod 三件套（MySQL 8.0 + Flask API + Angular/Nginx）已在 jimmyuser2 以 Docker 容器运行。

cpolar 公网穿透

最终方案：cpolar 二进制 + systemd 服务（放弃了 Docker 容器方式，因为 jimmyuser2 拉不到 Docker Hub 镜像）。

  • cpolar 3.3.12，从本机下载 scp 过去绕过网络限制
  • systemd 管理，Restart=always 开机自启
  • 隧道 mfs-web → 端口 80，暴露 prod 前端到公网

踩坑记录

  • Docker Hub 在 jimmyuser2 上完全不通（GFW），alpine 镜像都拉不到
  • cpolar.com 在 jimmyuser2 上也超时，只能本机下载再 scp
  • sudo + heredoc 通过 SSH 执行时管道会冲突，改用 printf > tmpfile 再 cp 的方式解决
  • cpolar 本地 API（9200/4042）在 systemd 模式下不开放，公网地址需要去 dashboard.cpolar.com 查看

Next Steps

  • 确认 cpolar 公网 URL 可正常访问 prod 前端
  • 后续考虑买域名 + Oracle Cloud 免费 VPS 替代 cpolar（带宽和稳定性更好）
