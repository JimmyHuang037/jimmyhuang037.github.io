7/30 Database Backup & Production Deployment & Teacher Stats Fix

angular docker database devops fullstack flask bugfix

数据库自动备份系统

给 MFS 项目加了一套完整的数据库备份/恢复方案：

  • scripts/db-backup.sh — 通过 SSH 远程备份 ubsrv 上的 MySQL（dev + test 两套）
  • 支持 backup / restore / list / cron 四个子命令
  • 备份文件 gzip 压缩，存放在 db/backups/
  • 自动清理超过 7 天的旧备份
  • crontab 凌晨 3:00 自动执行，无需人工干预

实测两套环境各 92K，备份秒级完成。

生产环境部署

把 MFS 推上了生产，跑在 jimmyuser2 VM（Ubuntu 25.04, 2G RAM），通过 cpolar 暴露公网。

架构

3 个 Docker 容器，docker-compose.prod.yml 编排。生产机上没有源码，只有镜像 + compose + .env + 初始化 SQL。

Build → Ship → Run

不在生产机 git clone 整个仓库（里面有 dev/test/prod 三套配置 + 源码 + e2e 测试），采用镜像交付：

  1. Build：jimmyuser1（开发机）docker compose build --no-cache api web
  2. Ship：docker save | ssh prod 'docker load' 管道直传，不落盘
  3. Run：docker compose up -d

cpolar 公网穿透

VM 在 Hyper-V 内网（172.30.x.x），没有公网 IP，用 cpolar 做隧道：

  • cpolar 3.3.12，systemd 持久化，开机自启
  • 免费版：URL 每次重启随机分配，带宽 1Mbps，个人用够
  • 执行方式：cpolar http 80 -dashboard=on（不是 yml 配置隧道，免费版不支持）

老师端统计 Tab 数据修复

老师端”班级统计”和”同科对比”两个 Tab 只有框架没有数据，定位并修复。

根因：前端 getLatestDate() 传当天日期（2026-07-30），但 DB 里 exam_date 是数据生成时的日期（2026-02 ~ 05）。WHERE exam_date = '2026-07-30' 匹配不到任何记录。

修复：

  • 后端新增 resolve_exam_date()，exam_date 改为可选，不传时自动 SELECT MAX(exam_date) WHERE type = ?
  • 前端去掉 getLatestDate()，只传 type

4 个统计接口验证通过：班级排名、分数段、各科前三、同科对比。
